# Quickstart B16
Reutilizar [ambiente B02](../001-base-backend/quickstart.md), bancos locais dev/test e runtime fixado. Executar migrações, npm run build, Jest --runInBand, npm run lint e tsc --noEmit no backend.
Validar ordem A/B/C filtrada A/C; local novo pendente e publicação bloqueada; ordem padrão alterada preserva publicada até ação explícita; prévia obsoleta/conflito concorrente; cancelamento retira parada vazia; motorista alheio/revogado e fim de janela; plano substituído não reutiliza publicação anterior; rota automática desabilitada/saída inválida.
Cálculo viário real, mapas e frontend não fazem parte desta validação.
